OPEN-SOURCE VIDEO CLIPPING · RUNS ON YOUR COMPUTER

The good parts.
Ready to share.

Chopify turns podcasts, movies, streams, and gameplay VODs—local files or YouTube links—into captioned clips for Shorts, Reels, and TikTok. It reads the speech, listens for reactions, and watches for action, then you review and export—all locally.

A WORKFLOW YOU CONTROL

Find. Refine. Export.

INPUT

Recordings or links

Read local MP4, MOV, MKV, WebM, M4V, and AVI files, or download supported video URLs. Batch several sources into separate projects.

REVIEW

A local browser workspace

See progress, watch candidate moments, adjust clip boundaries, and select your exports. Fast drafts help you review before the final render. For long URLs, Watch renders a 480p draft from just that downloaded section.

SELECTION

Every clip that passes

Absolute 0-10 scoring returns every clip at 8.0 or higher by default, with no fixed ten-clip cap. Length is chosen per moment from a 15-300 second range; a preferred length is a soft hint, not a hard cut.

CONTINUITY

Pick up where you left off

Matching downloads, transcripts and successful clips stay cached. Failed jobs can be retried without throwing away completed work.

CAPTIONS

Correct the words

Edit transcription text and timestamps. Export burnt-in word-by-word captions and a separate clip-relative SRT file, including retimed tightened cuts.

STYLE

Caption Studio

Start from 13 distinct looks, then tune font, size, colors, outline, shadow, cue length, position, box background, and word motion. A live overlay follows the source, with optional automatic emphasis and emoji.

IDENTITY

Make the style yours

Reuse JSON presets for fonts, colors, size, position, caption motion, and an optional logo. Save a project look as a named preset for future videos. Export in 16:9, 9:16, or 1:1.

DISCOVERY

Find more than words

Local audio energy and visual action evidence surface reactions, impacts, scene changes, and gameplay moments. Speech-sparse and no-commentary VODs can score from media evidence, with text as the fallback when media evidence is unavailable.

SEARCH

Find a topic by meaning

Use keywords, automatic scoring, or optional local Ollama embeddings to find related ideas. The transcript does not need to contain the exact query words.

PODCASTS

Keep both people in frame

Stack two adjustable crops in a vertical video for fixed-camera interviews. Set each speaker's horizontal position and check a draft.

FINISH

Clips and useful sidecars

Save H.264 MP4, SRT subtitles, a PNG poster, and title/description/hashtag JSON. Optionally remove fillers and pauses or normalize loudness.

Scores guide editing decisions; they do not predict virality. Review captions and clip boundaries. Speech-sparse and silent sources still need usable audio variation or visible action. Hooks for wordless footage describe timestamps, never guessed events. Caption Studio's overlay approximates the exported libass render. Split-screen uses fixed centers, not speaker recognition.

GET STARTED ON WINDOWS

Your machine.
Your cutting room.

Install Python 3.11+ and a full ffmpeg build, then open Studio. The dashboard needs no separate web framework or JavaScript build.

First use downloads the speech model. URL inputs need internet. Local-file processing can run offline once the required dependencies and models are available.

POWERSHELL 
git clone https://github.com/mehbul/chopify.git
cd chopify
winget install Gyan.FFmpeg
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python dashboard.py

Open http://127.0.0.1:8765 on this computer.

PREFER THE TERMINAL?

One pipeline. Two ways to work.

python chopify.py "C:\Videos\podcast.mp4" --aspect 9:16 --layout split

The CLI shares Studio's project runner. Prepare candidates, inspect the saved JSON, render a subset, resume a job, or process a batch. Caption presets and controls have matching flags such as --style, --words-per-cue, and --caption-json. Read the CLI and API reference ↗

BEFORE YOUR FIRST CUT

Questions, answered.

What is Chopify?

Chopify is a free, MIT-licensed local video clipper for turning long videos into short captioned clips. It includes a browser dashboard, Python CLI, transcription, selection, reframing, editing, and export.

Does it work with gameplay VODs and videos without commentary?

Yes, when there is usable evidence. Chopify builds a local audio timeline and samples the picture for motion, scene and UI changes, faces, action arcs, and quiet boundaries. Speech-sparse clips use a text floor and stronger evidence weighting. Silent no-commentary gameplay can score from visual action alone; flat footage with no speech and no media variation is reported instead of inventing a clip.

Is there a duration limit?

No fixed ceiling. Sources of 2 hours or more, an 8 GB estimated download, or unknown duration use the automatic long path: audio-first ingest, 30-minute resumable transcription chunks, 30-minute discovery blocks, and section-only rendering. Local long files are read in place. Long URL projects preview a candidate by rendering a 480p draft from its downloaded section.

Is Chopify an alternative to Opus Clip?

It is an option for creators who want clipping, captions and review on their own computer. It requires local installation and your hardware. It does not include hosted processing, cloud collaboration, or automatic social publishing.

Can I use it with no API key or subscription?

Yes. Default selection is a deterministic heuristic. Optional AI selection and semantic search use local Ollama models. Setup/model downloads, storage, and compute are supplied by you.

Can I edit, style, and export captions?

Yes. Edit words and their times in Studio's Transcript tab. In the Captions tab, choose one of 13 presets and tune font, size, colors, outline, shadow, cue length, position, background, and word motion. The overlay follows the source; 5-second previews show the look in motion. Save a project style or a reusable named preset, then export. Each draft and finished clip includes a separate SRT file aligned to its own timeline.

Does it upload my footage?

Chopify does not send footage or transcripts to hosted processing. Online sources and first-run model setup require downloads. Studio serves only your loopback address and is intended for one trusted local user.

What are the limitations?

Speech recognition and caption timing need review. Speech-sparse and silent sources need usable audio or visual evidence; scores do not predict virality. Caption Studio's overlay approximates the exported libass render, and emoji glyphs need a system emoji font. Heuristic cue lists are English-oriented. GPU speech acceleration uses NVIDIA/CUDA; CPU works without it. Split-screen uses fixed crop centers. Translation, dubbing, scheduling, and social uploads are not included.
